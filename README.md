# Nuxt App 🚀

A modern Nuxt project with Tailwind CSS, Playwright testing, and various powerful libraries.

## 📦 Tech Stack

### **Frontend**

- ![Nuxt](https://img.shields.io/badge/Nuxt-3.16-green?logo=nuxt.js&logoColor=white) – Powerful Vue-based framework
- ![Vue](https://img.shields.io/badge/Vue-3.5-%23308A43?logo=vue.js&logoColor=white) – Progressive UI framework
- ![Tailwind CSS](https://img.shields.io/badge/TailwindCSS-4.1-%2338B2AC?logo=tailwind-css&logoColor=white) – Utility-first CSS framework
- ![Pinia](https://img.shields.io/badge/Pinia-3.0-yellow?logo=vue.js&logoColor=white) – Vue state management alternative
- ![Iconify](https://img.shields.io/badge/Iconify-Heroicons%20MDI-%23FFDD00?logo=iconify&logoColor=white) – Extensive icon library
- ![Sass](https://img.shields.io/badge/Sass-Embedded-%23CC6699?logo=sass&logoColor=white) – CSS preprocessor for styling flexibility

### **Testing & Code Quality**

- ![Playwright](https://img.shields.io/badge/Playwright-1.52-%23FF33A1?logo=microsoft&logoColor=white) – End-to-end browser testing
- ![ESLint](https://img.shields.io/badge/ESLint-9.25-%23363636?logo=eslint&logoColor=white) – Code linting for consistent styling
- ![Prettier](https://img.shields.io/badge/Prettier-3.5-%23005F9E?logo=prettier&logoColor=white) – Code formatter for clean syntax

### **Backend & API**

- ![Axios](https://img.shields.io/badge/Axios-1.9-blue?logo=axios&logoColor=white) – HTTP client for API requests
- ![Dotenv](https://img.shields.io/badge/Dotenv-16.5-%2333CC99?logo=dotenv&logoColor=white) – Environment variable management

### **Build & Tooling**

- ![Vite](https://img.shields.io/badge/Vite-%230076ff?logo=vite&logoColor=white) – Lightning-fast development tooling
- ![TypeScript](https://img.shields.io/badge/TypeScript-5.8-%23007ACC?logo=typescript&logoColor=white) – Type safety for JavaScript

## ✨ Features

- Nuxt 3 framework for modern Vue development
- Tailwind CSS for styling
- Pinia for state management
- Playwright for end-to-end testing
- Prettier & ESLint for code formatting & linting
- TypeScript support

## 🚀 Getting Started

### Installation

Clone the repository and install dependencies:

```sh
git clone https://github.com/Matt443/ip_calculator_UI.git
cd ip_calculator_UI
npm install
```
